# 💌 디지털 롤링페이퍼 (Digital Rolling Paper)

누구나 접속하여 따뜻한 축하와 응원의 메시지를 남길 수 있는 공개 디지털 롤링페이퍼 웹 서비스입니다.  
**Supabase(데이터베이스)** 와 **Vercel(호스팅)** 을 연동하여 전 세계 어디서나 접속할 수 있는 나만의 웹사이트를 만듭니다.

---

## 🛠️ 기술 스택
- **Frontend**: HTML5, Modern CSS3, JavaScript (Vanilla ES6)
- **Database**: Supabase (PostgreSQL)
- **Deployment**: GitHub + Vercel

---

## 📋 [1단계] Supabase(수파베이스) 데이터베이스 설정하기

### 1. 프로젝트 생성
1. [supabase.com](https://supabase.com)에 로그인합니다.
2. 화면 우측 상단의 **[New project]** 초록색 버튼을 클릭합니다.
3. Organization을 선택하고, 정보를 입력합니다:
   - **Name**: `rolling-paper` (원하는 이름 입력)
   - **Database Password**: 비밀번호를 입력하고 꼭 메모해둡니다.
   - **Region**: `Seoul (ap-northeast-2)` 또는 `Tokyo (ap-northeast-1)` 선택
4. **[Create new project]** 버튼을 클릭하고 약 1~2분 기다리면 프로젝트 생성이 완료됩니다.

---

### 2. SQL문 실행하여 테이블 만들기
1. 왼쪽 메뉴 아이콘 중 **[SQL Editor]** (터미널 모양 `>_` 아이콘)를 클릭합니다.
2. 화면 상단의 **[+ New query]** 버튼을 클릭합니다.
3. 아래의 SQL 코드를 복사하여 쿼리창에 그대로 붙여넣습니다:

```sql
-- 1. 롤링페이퍼 메시지를 저장할 messages 테이블 생성
create table messages (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  author text not null,
  content text not null,
  color text default 'yellow'
);

-- 2. 모든 사람이 읽고 쓸 수 있도록 보안(RLS) 활성화
alter table messages enable row level security;

-- 3. 누구나 메모를 조회(SELECT)할 수 있는 정책 생성
create policy "누구나 메시지 조회 가능" on messages
  for select using (true);

-- 4. 누구나 새 메모를 작성(INSERT)할 수 있는 정책 생성
create policy "누구나 메시지 작성 가능" on messages
  for insert with check (true);
```

4. 우측 하단의 초록색 **[Run]** 버튼(또는 단축키 `Ctrl + Enter`)을 누릅니다.
5. `Success. No rows returned` 메시지가 나오면 데이터베이스 준비 완료!

---

### 3. API 키 확인 및 `config.js` 수정
1. Supabase 왼쪽 메뉴 맨 아래의 **[Project Settings]** (톱니바퀴 ⚙️ 아이콘)를 클릭합니다.
2. **[API]** 메뉴를 클릭합니다.
3. 화면에서 아래 2가지 값을 복사합니다:
   - **Project URL**: `https://xxxxxxxx.supabase.co`
   - **Project API keys**의 `anon` `public`: `eyJhbGciOiJIUzI1NiIsIn...`
4. 내 컴퓨터의 `config.js` 파일을 열고 위 두 값을 붙여넣은 뒤 저장합니다:

```javascript
const SUPABASE_CONFIG = {
    url: '여기에_복사한_Project_URL_붙여넣기',
    anonKey: '여기에_복사한_anon_key_붙여넣기'
};
```

> 💡 **로컬 테스트**: `index.html` 파일을 더블클릭해서 브라우저로 열면, 바로 메시지를 남겨보고 DB에 저장되는지 확인할 수 있습니다!

## 🚀 [2단계] GitHub에 소스코드 올리기 (웹 브라우저로 1분 만에 끝내기)

터미널이나 명령어를 몰라도 **GitHub 웹사이트에서 파일 업로드**로 가장 쉽고 안전하게 올릴 수 있습니다.

1. [github.com](https://github.com)에 로그인합니다.
2. 우측 상단의 **[+]** 아이콘 클릭 -> **[New repository]** 클릭.
3. 설정 입력:
   - **Repository name**: `rolling-paper`
   - **Public** 선택 (누구나 볼 수 있게 공개)
   - 아래 체크박스들(Add a README file 등)은 **모두 체크 해제(비워둠)** 상태로 둡니다.
4. 초록색 **[Create repository]** 버튼을 클릭합니다.
5. 생성된 화면 가운데 쯤에 파란색 글씨로 **`uploading an existing file`** 링크를 클릭합니다.
6. 현재 내 폴더의 파일들(`index.html`, `style.css`, `app.js`, `config.js`, `README.md`)을 마우스로 드래그하여 웹페이지 상자에 놓습니다.
7. 화면 아래의 초록색 **[Commit changes]** 버튼을 누르면 업로드 완료!

---

## 🌐 [3단계] Vercel(버셀)과 연동하여 전 세계 배포 URL 만들기

1. [vercel.com](https://vercel.com)에 접속하여 **[Log In]** -> **[Continue with GitHub]**로 로그인합니다.
2. 대시보드 화면 우측 상단의 **[Add New...]** 버튼 -> **[Project]**를 클릭합니다.
3. 방금 만든 GitHub의 `rolling-paper` 저장소 옆에 있는 **[Import]** 버튼을 클릭합니다.
4. 설정 창이 나타나면 아무것도 수정할 필요 없이 기본값 그대로 둡니다.
5. 맨 아래 **[Deploy]** 파란색 버튼을 클릭합니다!
6. 약 10초 뒤 폭죽 애니메이션과 함께 **"Congratulations!"** 화면이 뜹니다.
7. 화면에 표시된 링크(`https://rolling-paper-xxx.vercel.app`)를 클릭하면 전 세계 누구나 접속할 수 있는 롤링페이퍼가 열립니다! 🎉
